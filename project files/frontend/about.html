About Blood Cell Classification

This application uses advanced machine learning techniques to classify blood cell images into categories such as Eosinophil, Lymphocyte, Monocyte, and Neutrophil. It helps in medical diagnostics by providing quick and accurate predictions.

How It Works

Upload an image of a blood cell, and our AI model will analyze it to determine the cell type. The system provides a confidence score for the prediction.

Technology

Built with Python (Flask backend) and HTML/JavaScript (frontend), utilizing deep learning models for image classification.
